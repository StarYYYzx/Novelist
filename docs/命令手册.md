### 0.2 `--provider` 选择（**最重要的坑**）
- **绝大多数命令的 `--provider` 默认是 `fake`**（测试替身，产出占位内容）——真跑必须显式传
  `--provider deepseek`。
- 可选值（2026-09-07 起，单轨工厂 `providers.create` 统一实例化）：
  `fake | scripted | deepseek | openai | qwen | kimi | glm | anthropic | ollama | vllm | custom`。
  详见 docs/07 §2.3/2.4（各预设默认 base_url/model/Key 环境变量表）。
- **连接透传选项**（涉及 LLM 的命令统一支持，优先级 `--api-key` 值 > 环境变量 > `.env`）：
  | 选项 | 说明 |
  | --- | --- |
  | `--api-key <key>` | 显式 API Key；不传则回退环境变量 / 本机 `.env` |
  | `--api-base <url>` | 自定义 OpenAI 兼容 base_url（覆盖预设默认；`custom` 必填） |
  | `--model <model>` | 覆盖该 provider 默认模型名 |
- deepseek 默认模型 `deepseek-v4-flash`（providers/deepseek.py:24，禁 pro，无需传 model）。
- **Key 存放（方案 A，2026-09-07）**：key 由 `providers/secrets.py` 统一遮蔽/注入，
  **不落 git 跟踪文件**。推荐写在 gitignored 的 `novel_workspace/.env` 或当前目录 `.env`
  （形如 `DEEPSEEK_API_KEY=sk-...`），或用启动时环境变量。
- **云端 AutoDL 与本地 LM-Studio 均已停用**（2026-09-06 拍板，2026-09-07 彻底删码）——
  `providers/lmstudio.py` 已删除，`lmstudio` 不再是合法 provider 值。

### 0.3 项目目录参数
- 顶层命令与多数 forge 子命令的第一参数 `DIRECTORY` 可省略：缺省取 workspace 根
  （`novel_workspace/`）下**唯一项目**；存在多个项目时必须显式传，如 `novel_workspace/proj-fame5-20260906-124016`。
- 部分命令用 `--dir` 选项而非位置参数（forge.review/approve/revise/switches/seed/ingest），以 `--help` 为准。

### 正文生成
| 命令 | 用途 | 关键参数 |
| --- | --- | --- |
| `chapter [DIR]` | **串行写一章**：圣经注入→事件循环生成→完整性校验→润色→编纂回写 | `--vol 1 --ch 1 --provider deepseek`；`--direct/--loop`（**默认直出**；`--loop` 走 Agent 工具循环，需 provider 支持 `tool_calling`，否则自动降级直出并留痕——2026-09-15 审计 AG-1/AG-18 起语义）；`--gen-tokens`（生成预算，建议 6000）；`--content-tokens`（正文预算）；`--max-events N`（每片段事件上限）；`--min-event-words 120`；`--polish`（章级润色）；`--event-polish`（事件级润色，fame5 已开）；`--no-bible`（跳过圣经注入）；`--event-loop/--no-event-loop`；`--readback`（前文回读）；`--seam-review/--no-seam-review`（默认**开**）；`--volume-facts/--no-volume-facts`（默认**开**）；`--no-jit`（跳过 JIT 角色告警）；`--supplement-settings`；`--agentic-chronicle`（ADR-032 F1：编纂走只读证据仲裁环，落库前 `query_memory` 查冲突再裁决）；`--agentic-review`（ADR-032 F2：审校走只读证据环，可疑点取证后再定论） |
| `draft [DIR] [CHAPTER]` | **草稿溯源汇报**（ADR-030 · M3z 批次B）：汇报该章草稿生成时依赖的人物卡/线索/世界规则/设定/记忆基线/prompt 指纹/provider | `CHAPTER` 形如 `1-3`/`1:3`，**缺省=列全部已有源清单章节**；`--text`（连草稿正文一起打印）。每次 `chapter` 成稿自动落 `drafts/chapters/<vol>-<ch>.src.json` |

#### `chapter` 参数分组与 `[generation]` 项目级默认（U7，2026-09-15）

`chapter` 约 30 个参数分四组（`novelist chapter --help` 末尾同文）：
①**目标与后端**（`--vol/--ch/--provider/--api-*/--direct/--loop/--policy`，不进配置）；
②**预算与事件粒度**（`--gen-tokens/--content-tokens/--max-events/--min-event-words`）；
③**管线开关**（`--polish/--no-bible/--event-loop/--screenplay/--readback/--event-polish/
--supplement-settings/--no-jit/--seam-review/--volume-facts`）；
④**Agent 审查**（`--agentic-chronicle/--agentic-review` 及 `--rounds`，ADR-032）。

②③④ 可写入**全局配置文件**（`--config` 指定）的 `[generation]` 段作项目级默认；
键名 = 选项名去连字符，布尔键用**肯定式**（CLI 的 `--no-bible/--no-jit` 对应
`inject_bible`/`jit_characters`）。优先级：**显式 flag > 配置 > 出厂默认**
（无配置段时行为与历史版本一致）。未知键直接报错（防拼错静默失效）。示例：

```toml
[generation]
event_loop = true
polish = true
gen_tokens = 6000
min_event_words = 120
```

## 2. forge 子命令组（17 个，按工作流分四段）

```bash
cli forge <子命令> ...
```

### 2.1 建书（三选一）
| 命令 | 用途 | 关键参数 |
| --- | --- | --- |
| `seed BRIEF` | **模式一**：一句话创意 → 商讨/提炼 → 全权构建 | `BRIEF` 为位置参数（创意文本）；`--mode auto\|interactive`（interactive 走分轮商讨）；`--provider deepseek`；`--genre-pack id`；`--volumes/--chapters-per-volume/--target-words`；`--max-calls`（构建配额；**不传则按 N/K/M 规模推导**，ADR-033 B）；`--max-depth 4 --max-width 4 --max-width-list 12`（递归硬边界；长尾列表型宽度，ADR-033 A）；`--smoke`（只提炼+蓝图不构建） |
| `ingest SOURCE` | **模式二**：已有稿子 → 蓝图+章节+记忆初始化（支持 .docx/.md/.txt） | `SOURCE` 为位置参数；`--recursive`（扫子目录）；`--dry-run`（只切章预览）；`--chapters-per-volume 20 --target-words 2400`；`--ingest-max-calls 30`（超配额降级纯确定性） |
| `resume [DIR]` | 断点续跑：商讨中断→续问答；构建中断→幂等续构建 | `--max-calls 60 --provider deepseek --no-deepen`（跳过旁支深化） |

### 2.2 构建与快照
| 命令 | 用途 | 关键参数 |
| --- | --- | --- |
| `build [DIR]` | 重跑构建引擎（蓝图已有时），provenance 保护+幂等落盘 | `--force`（已有 chapters/ 时强制）；`--no-deepen`；`--diff`；`--max-calls`（不传则规模推导，ADR-033 B）；`--max-width-list 12`（长尾宽度，ADR-033 A） |
| `snapshots [DIR]` | 列出快照（build/roll 前自动生成） | — |
| `rollback [DIR]` | 回退到构建前快照：恢复文件+删新增产物 | `--to 快照名`（缺省最近一个） |
| `validate [DIR]` | V1–V6 契约校验 + 报告双写（M3l F5） | `--smoke`；`--settings-min 5`；`--no-report` |

### 2.3 滚动细纲（逐卷推进）
| 命令 | 用途 | 关键参数 |
| --- | --- | --- |
| `roll VOL [DIR]` | 滚动生成第 N 卷细纲（**需前卷已有正文**），注入前卷事实四块 | `--provider deepseek --max-calls 40`；`--gate/--no-gate`（蓝图审查+细纲连读，默认 gate） |
| `roll-window VOL [DIR]` | **未来窗口滚动**：修订第 N 卷尚未成文的下 N 章 key_events（ADR-026） | `--from CH`（起始章）；`--width 3`（窗口宽度）；触碰承诺条目→转 ADR-024 人工审核闸门，不静默改 |

### 2.4 审核流与工具
| 命令 | 用途 | 关键参数 |

## 4. 典型全链路（一本新书从 0 到发布）

```bash
export PYTHONPATH=src
CLI="C:/Python314/python.exe -m novelist.cli"

# ① 建书（模式一，商讨式）：一句多线新需求 → 拍板 → 全权构建
$CLI forge seed "男频修仙，声望系统，慢热开局" --mode interactive \
     --provider deepseek --volumes 3 --chapters-per-volume 8

# ② 逐章写正文（fame5 实测配置：事件循环+事件级润色+接缝审查+卷事实）
#   默认就是直出（--direct 可省略）；--loop 是 Agent 工具循环的实验开关
$CLI chapter --vol 1 --ch 1 --provider deepseek --direct \
     --gen-tokens 6000 --event-loop --event-polish --readback

# ③ 一致性审查（语义审校走 deepseek）
$CLI review --provider deepseek

# ④ 转正 + 门禁处理
$CLI promote --vol 1 --ch 1
$CLI grant                      # 有待决审批时逐条 --approve/--deny

# ⑤ 下一卷细纲（前卷写完后）
$CLI forge roll 2 --provider deepseek

# ⑥ 导出成书
$CLI export --format docx --out 成稿.docx
```

存量稿子改书：`$CLI forge ingest 稿子目录 --recursive --provider deepseek`（先 `--dry-run` 预览切章）。
断点续跑：商讨/构建中断后 `$CLI forge resume --provider deepseek`（幂等，跳过已落盘节点）。

## 7. 常见坑速查

| 坑 | 后果 | 正确姿势 |
| --- | --- | --- |
| 忘传 `--provider deepseek` | 生成结果是 fake 占位文本 | 真跑一律显式传；review 同理 |
| `chapter` 用默认 `--direct` | **这是正确姿势**（2026-09-15 起默认即直出）；`--loop` 工具循环需 provider 支持 `tool_calling`，否则自动降级直出并留痕 | 真机写章保持默认；`--loop` 仅在明确要跑工具循环时用 |
| cloud/lmstudio 相关旧文档 | 跑不通或连接拒绝 | 2026-09-06 起均停用，一律 deepseek |
| promote 忘 `--policy` | sensitive 操作交互卡住 | 策略文件 `sensitive=allow` 或走 `grant` |
| roll 未写完前卷正文 | 前卷事实四块缺数据 | 先写完前卷再 roll；或用 roll-window 只动未来章 |
| 人工改细纲后直接续写 | 账本与细纲脱节（F2 教训） | 改完跑 `forge lines-replay --vol N --ch M` 转正 |
| 修订触碰已承诺伏笔/主线 | 走向失控 | `roll-window` 自带承诺门控；手动改前先看 `forge covenant` |

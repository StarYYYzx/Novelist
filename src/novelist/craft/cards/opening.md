# 黄金三章

> 新卡（2026-10-25），内容源自调研报告（2026-10-24）§3.2/§7。
> 开篇抓人的窗口已从"章"压缩到"段"再压缩到"句"（三句话不劝退）——
> 原理没变，变的是窗口长度。本卡规范**前 3 章**；此后节奏归
> chapter-rhythm 卡、爽点结构归 shuangwen 卡。

## 一、三章功能分配

| 章 | 功能 | 结构 |
|---|---|---|
| 第一章 | **立困境 + 给转机 + 抛钩子** | 前 300 字内主角处境与危机可见 → 中段给出金手指/奇遇/反转 → 结尾留悬念 |
| 第二章 | **展示能力 + 小试牛刀 + 新威胁** | 金手指有用但别一次爽完；给一个小胜利，同时引入更强敌人 |
| 第三章 | **第一次小高潮 + 长线目标** | 完成第一个完整小循环，立起贯穿全书的期待（范式：三年之约） |

## 二、平台开篇档（与 chapter-rhythm 卡的节奏三型联动）

- **起点**：卖点前移到简介头两行；**第一章承担全书"封面"功能**——
  用一整章完成一个完整的起承转合并构建大期待；人物背景放第二章
  （"如今的第二章，才是过去的第一章"）。
- **番茄**：前 300 字必须引爆冲突（危机开局：主角正处在麻烦中；
  或反转开局：上一秒正常、下一秒惊天反转）；**三句话不劝退**；
  禁大段写景、大段心理、冗长背景。
- **飞卢**：书名+简介即抛出最大期待；第一章主角现状+需求+金手指+
  困难全套出齐。

## 三、开篇铁律

1. **冲突前置**："第一章就要有委屈"——且委屈必须**被读者看见**
   （写场景不写概括，见 shuangwen 卡期待三件套）。
2. **聚焦主角**：开篇视角必须在主角身上，绝不在龙套/无关配角；
   减少无关人物（开篇人名 ≤5 个）。
3. **零信息轰炸**：禁三页世界观、禁十几个人名、禁王朝兴衰史——
   设定拆碎了伴随情节出现，永不单开段落解释。
4. **金手指亮相不晚于第二章**（最好第一章中段）。
   边界提醒：存在"第一章全程不出现金手指、纯靠悬念抓人"的成功范本，
   但那是头部作者在题材红利期的打法（且第二章起立即密集埋线索）——
   新书不得只学其第一章。
5. **开篇明志**：第一章就确定风格与路线（题材基调/主角底色），
   不得写成"什么都有点"的大杂烩。

## 四、反模式（禁止）

- 第一章甩几百年历史、势力图、十几个人名（开局信息轰炸，第二大弃书点）。
- 开篇视角给龙套（错误排行榜第二）。
- 前 300 字无冲突、大段写景抒情。
- 金手指拖到第三章以后（第三章前读者不知"这本书爽什么"）。
- 照抄大神的慢热开篇——大神有粉丝信用垫底，新书开篇慢热=死。

## 五、对设定阶段的要求

- 平台档与金手指亮相位置（knobs 两项）
- 第一章的开局类型（危机开局 / 反转开局 / 现状+金手指开局）
- 长线目标的形态（第三章立起的贯穿全书期待是什么、倒计时多久）

# 爽文

> v2（2026-10-25）并入调研报告（2026-10-24）的"期待—延迟—兑现"理论骨架。

## 一、本体定义（爽点是什么）

1. **爽点不是事件，是心理落差**：打脸、升级、暴富、复仇只是兑现方式；
   爽点是"读者预期他会怎样被对待，现实给了另一个答案，且更符合读者
   心里那杆秤"。落差越大爽感越强。第一性设计问题不是"怎么让他赢"，
   是"**怎么让读者先替他憋着**"——没人替他不平的主角，赢了也没人痛快。
2. **发动机：先抑后扬造落差**。憋屈写足再翻盘；但压抑必须受控、必须回账。
3. **四种读者心理**（每个爽点须落到至少一种）：补偿（公平与报复快感）、
   掌控（信息差与预判）、认同（自尊与被仰望）、奖励（升级得宝短频快）。
4. **爽点类型**：明爽（当众打脸）、暗爽（只有我知道的碾压）、
   迪化爽（误读与脑补的反差）；情绪爽点尽量与利益爽点叠加兑现。

## 二、期待段：三件套（缺一读者就"关我什么事"）

1. **标准**——读者知道"正常应该怎样"（救人全家者该被当恩人待；
   没有标准就没有"不该"）。
2. **处境**——他现在被怎样对待，且必须**被看见**而非被叙述
   （"他在家族里不受待见"是叙述；"年夜饭上，他的碗被放在小孩那桌"
   是被看见）。
3. **筹码**——他手里有什么（秘密、证据、一身本事、一个没打出去的电话）。

## 三、延迟段：蓄压不是注水

- 延迟的本质是"让读者在'他随时可以动手'的状态下等"。
- **每三千字至少一次加码**：对方更过分 / 退路被堵死一条 /
  有人开始替他不平 / 一个倒计时被点亮——延迟期内没有新信息就是注水。
- 压抑配比：单元内压抑段占比不超过 30%；主角受挫后快速回账
  （回账上限设定阶段拍板）；可以加挫折，**禁虐主**。
- **期待感保全**：主角可以暂时弱势但绝不能窝囊——每次受挫须有反抗信号。

## 四、兑现段：三形态与超预期

1. **力量型**：藏的东西亮出来（要求前面埋过哪怕一句）。
2. **规则型**：不靠更强，靠更懂规则，把对方的优势变成劣势——
   爽感更持久，因为它让读者觉得"聪明"而不只是"强"。
3. **关系型**：一句话让全场重新认识他，解决"人"而非"事"。
   **最好的兑现是三者叠加**；兑现必须同时满足"超预期"且"合理"。
4. **该慢写的是兑现前那一口气**：最爽的往往不是打脸那一刻，
   是打脸前的那一秒——对方还在得意，读者已知道接下来要发生什么。

## 五、排布纪律

1. **轮换类型**：力量/规则/关系交替；连续三次力量型读者会疲劳
   （"他已经知道结局的形状"）。
2. **间距**：大爽点之间留够呼吸；连续两次大高潮第二次一定贬值；
   大高潮之间留**回气段**（处理后果、修复关系、铺新线）。
3. **大前有小**：大爽点前先给一两个小爽点——小爽点的作用是
   "证明这个作者会兑现"。
4. **打脸升级阶梯**：个人→权威→智谋→权力→公开→制度；
   同层级打脸重复至多 2 次后必须升级。
5. **标准循环**（土豆式四拍）：遇敌受挫→得底牌→蓄力→当众打脸，
   一轮结束立刻开启下一个目标，每 20–40 章走一轮。

## 六、反模式（禁止）

- **爽点通货膨胀**（最隐蔽的长篇死因）：这次爽得太狠，下次必须更狠，
  剂量越滚越大，透支后段空间——"不是作者不会写了，是前面把后面爽完了"。
- **期待不足就兑现**：被骂一句当场还回去，读者觉得"这不是应该的吗"。
- **延迟没有信息**：反派反复挑衅主角反复忍——读者不是不能等，是不能白等。
- **兑现不够狠**：铺垫二十章的高手一招就输——"情绪投进去没收回来，
  这比不给还伤人"。
- **虐主 / 注水 / 同级打脸复读 / 空降反转 / 反派降智 / 主角窝囊 /
  成功烂大街**（v1 各条全部保留）。

## 七、对设定阶段的要求

勾选本卡时，设定敲定阶段需额外拍板：
- 全书低谷/高潮锚点表（各卷的大不爽与大爽）与回账上限
- 打脸阶梯规划（各层级对应的反派与场合）
- 爽点密度预算（每卷大小爽点数量）与兑现类型轮换表
- 反派智商下限共识（哪些错误反派不会犯）
- 金手指与爽点的服务关系确认（金手指卡若启用，须一致）

【爽文情绪工程规范（本书为爽文节奏结构，硬约束）】

1. 爽点是心理落差：先立期待三件套——标准（正常应该怎样）、处境（被怎样对待，
   必须写出来让读者看见，不得用叙述带过）、筹码（他手里有什么）；
   三样齐了才能进入延迟与兑现。
2. 延迟段每三千字至少一次加码（对方更过分/退路被堵/有人替他不平/倒计时点亮）；
   延迟期内没有新信息就是注水，禁止。
3. 压抑受控：单元内压抑段占比不超过 30%，主角受挫后快速回账；
   每次受挫必须有反抗信号，禁长期虐主、禁主角窝囊无反击。
4. 兑现三形态轮换：力量型（亮底牌，须前文埋过）、规则型（更懂规则以弱胜强）、
   关系型（一句话改变全场认知）；主要爽点尽量三选二以上叠加，
   且同时满足超预期与合理；连续三次同一形态必须换。
5. 该慢写的是兑现前那一口气：对方还在得意、读者已知结局的瞬间是情绪浓度
   最高点，不得匆匆带过。
6. 打脸层级递增：个人→权威→智谋→权力→公开→制度；同层级重复至多 2 次。
   标准循环：遇敌受挫→得底牌→蓄力→当众打脸，每轮结束立刻开下一个目标。
7. 大爽点之间留回气段（处理后果/修复关系/铺新线）；大爽点前先给一两个
   小爽点；核心爽点间隔不得超出设定上限。
8. 情绪爽与利益爽尽量双重落账；主角的成功绑定独有条件，配角不得轻易复现。
9. 反转必须有前文证据链；反派不降智，其失败须由主角方主动作为导致。
10. 严防爽点通货膨胀：每次兑现的剂量不得无上限递增——宁可下次换个类型，
    不得单纯把规模再加大一档。

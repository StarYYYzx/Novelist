# 诡异副本

## 一、本体定义（世界是什么）

1. **诡异**：无法用常理解释的异常存在——实体、禁忌、区域、现象。
   它有行为模式（出现条件、袭击规律、禁忌）可被观察、归纳、暂避、研究，
   但通常**不可被正面消灭**；给它"弱点"必须有前文伏笔。
2. **污染**：接触诡异有代价——认知扭曲、身体异变、记忆缺失。
   污染随接触深度递进，可见、可检测、可部分净化但净化有代价。
3. **副本**：封闭的异常区域（医院、村落、宅邸、学校），
   进入条件与出口条件明确；副本内通讯、求助、撤离受限。
4. **主角优势**：观察力、常识与知识（民俗/职业/理性思维），
   而非战力——诡异副本的主角是"研究员"，不是"屠龙者"。

## 二、呈现规范（硬约束，人设/风格不得覆盖）

1. **先异常后解释**：先呈现异常现象，解释延后到节点；
   禁止开场大段世界观说明。每一屏至少一处异常、信息揭露或死亡风险。
2. **未知感纪律**：诡异核心形态长期不完全展示——
   写声音、爪印、影子、影响（门自己开了、物件位移），不写正脸全貌；
   关键揭露留到剧情节点，留白比展示更恐怖。
3. **常识破坏**：每个副本至少一处"熟悉事物异常化"
   （镜中影像不同步、时间错乱、熟悉物件出现在不可能的位置），
   用反差制造不安。
4. **孤立设计**：副本内的通讯/求助/撤离限制必须在进场时明确；
   中途不得无代价地恢复外援。
5. **污染记账**：主角与队友的污染状态是硬状态——逐次累积、
   可检测（症状分级）、不得无故清除；净化必须有代价与周期。
6. **诡异有行为模式**：出现条件、袭击规律、禁忌可被观察归纳；
   主角靠规律活命。禁止临场发明对策（"它怕光"必须前文埋过）。
7. **恐怖画面具体而克制**：用具体物件承载恐怖
   （红鞋、礼账本、宿舍第五张床、空白答题卡），段落短、换气快；
   血浆猎奇克制，写感知与反应。
8. **死亡留账**：副本内死亡真实，禁暗复活；
   出口与结算（或逃离）条件在进场阶段即明确。

## 三、长篇节奏模板

| 层 | 该发生什么 |
|---|---|
| 第一卷 | 新手副本：异常递进（脚步声→物件异动→首次目击）→ 首次减员 → 靠规律完成第一次逃离/反制 |
| 中间各卷 | 探索→回溯→解谜→逃离/反制循环；诡异图鉴扩充；污染账户累积成卷级危机 |
| 后期 | 诡异源头/世界观真相收拢：各副本的异常串成同一根源 |
| 每卷 | 至少一次"安全区失效"升级（本以为安全的地方/规则/伙伴不再安全） |

## 四、反模式（禁止）

- **战力平推**：主角练级后把诡异当怪刷——诡异不可正面消灭是类型底线。
- **全知旁白**：叙述者提前解释诡异底细，恐惧被剧透殆尽。
- **随机化诡异**：诡异无规律、剧情需要才出现、事后无解释。
- **血浆堆砌**：猎奇描写代替氛围与未知感。
- **污染白嫖**：主角反复深度接触诡异却毫发无损。
- **NPC 工具人**：副本人物只有死亡功能，无行为逻辑。

## 五、对设定阶段的要求

勾选本卡时，设定敲定阶段需额外拍板：
- 诡异图鉴：每个异常实体的出现条件、行为规律、禁忌、可利用点
- 污染分级表（等级、症状、检测方式、净化代价）
- 副本清单（至少 5 个候选副本的一句话概念 + 封闭机制 + 出口条件）
- 主角知识型金手指的边界（懂什么、不懂什么、何时失效）
- 诡异源头真相（一句话，后期收拢用）

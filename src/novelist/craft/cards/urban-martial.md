# 都市高武

## 一、本体定义（世界是什么）

1. **双层世界**：明面（普通人的现代都市：法律、媒体、学校、职场）+ 武道面
   （官方机构、武馆、世家、隐世势力）。两层不是平行世界——同一座城，
   普通人只是看不见或选择性忽略武道面。
2. **力量即制度**：武道等级是被官方承认、公开可查的社会身份
   （登记、评级、执照、任务权限）。体系拒绝玄学模糊：等级、战力、资源
   **皆可量化、可检测、可考核**。
3. **资源闭环**：修炼资源（功法、药剂、场地、装备）高度商业化，
   获取方式直接映射社会身份——金钱、任务功勋、家族、黑市是四条主要
   来源，主角每一步成长都要落账。
4. **危机源**：本书必须有一个世界级威胁（异兽、空间裂缝、入侵），
   它为"为什么需要武者"提供合法性，也是官方体系的权力来源。

## 二、呈现规范（硬约束，人设/风格不得覆盖）

1. **现代常识铁律**：器物、法律、医学、通信、舆情的运作必须符合当代逻辑。
   称谓用现代称呼（老师/教练/同学/先生）；古风称谓（在下/阁下）只允许出自
   刻意扮古的角色，且须被环境视为异常。
2. **战力锚定**：武者实力必须用现代参照物量化（拳力公斤级、百米秒表、
   破坏的混凝土标号），禁止"强大无比/深不可测"式虚写。
   等级表一旦公开，全书不得悄悄改写。
3. **暴露即资源**：在普通人面前展示超常战力是**消耗性剧情资源**——
   每次公开暴露都要有后果（围观拍摄、舆情、官方约谈、世家注意）。
   主角的大规模暴露全书前期至多 2-3 次，且每次必须升级为事件推进剧情。
4. **官方在场**：官方武道机构必须是活的存在（评级、任务、执法、救济）。
   主角可以与体制疏离，但不得长期无后果地游离——违法用武要被追责，
   立功要被认证。
5. **金钱账**：武道资源要花钱。主角的经济来源、开销、缺口要能对账；
   禁止凭空变富或无限白嫖。
6. **双线配比**：都市生活线（学业/职业/家人/朋友）是人格与代价的地基；
   连续纯武道打斗不得超过 3 章，必须回都市线补给人物关系与行为动机。

## 三、长篇节奏模板

| 卷 | 该发生什么 |
|---|---|
| 第一卷 | **制度性呈现**：主角在评级/考核体系中被否定或低估，拿到金手指后完成第一次制度内打脸（考核/比武/任务） |
| 中间各卷 | **实践性爆发 → 政治性博弈**：荒野/秘境实战建立战力实证，随后卷入官方与世家/财团的规则博弈 |
| 后期卷 | **本体性觉醒**：主角重塑或改写体系规则，而非仅在旧体系内登顶 |
| 每卷 | 至少一次"公开评级/认证"事件作为战力里程碑与爽点节点 |

## 四、反模式（禁止）

- **古装武侠换皮**：去掉手机、警察、学校后毫无违和的"都市"是失败品。
- **路人失聪**：超常战斗发生在闹市却无人拍摄、无舆情、无官方响应。
- **数值崩坏**：低两级稳定打赢高两级且无代价无解释；越级战必须有
  战术/资源/环境理由并留下战损。
- **世家脸谱化**：所有世家子弟都是纨绔反派——必须存在正面或复杂的
  世家人物。
- **危机源摆设**：世界级威胁与主角成长线无交集，只存在于设定里。

## 五、对设定阶段的要求

勾选本卡时，设定敲定阶段需额外拍板：
- 力量等级全表（名称、量化指标、对应社会权限）
- 官方机构名称、层级与对主角的态度曲线
- 主角的都市身份锚（学业/职业）与经济模型
- 世界级威胁的形态与公开程度
- 暴露政策（主角对外公开战力的上限与策略）

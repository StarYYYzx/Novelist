# 规则怪谈

## 一、本体定义（世界是什么）

1. **长篇怪谈 ≠ 短文本怪谈**：短文本怪谈只展示规则、靠纯粹未知恐惧；
   本题材是**以规则为骨架的长篇小说**——主角要活下来、解开真相、完成成长。
   写成纯文本怪谈会缺少故事性。
2. **诡异受规则约束**：诡异存在同样必须按规则行事，不能随意杀人——
   这给主角和读者一个"可研究的敌人"，规则是攻防两端的契约。
3. **规则文本是核心叙事装置**：每条规则都有来源（守则/残页/口述/标识）、
   有制定者、有真伪；规则清单本身就是待解的谜面。
4. **底层真相**：所有规则由同一个底层真相派生（曾发生过什么），
   规则之间方向可以不同，但内在逻辑必须一致。

## 二、呈现规范（硬约束，人设/风格不得覆盖）

1. **真相先行**：每个怪谈场景必须先设定底层真相，再逆向推导全部规则；
   禁止先写规则再补真相。解谜揭晓时，读者复盘必须"全都对得上"。
2. **规则显式呈现**：已知规则以编号清单原样给出（角色读到/听到/捡到）；
   **已公布的规则文本后文不得改写**。规则允许"腐烂"（随时间或条件增删字句），
   但每次变化必须可观察、可追溯、有前文证据。
3. **多重规则撕裂**：允许两套以上规则源部分重合、部分矛盾
   （员工守则 vs 旧笔记："黑衣人危险" vs "黑衣人会保护你"）；
   作者必须预先明确哪套为真、矛盾根源（制定者视角与目的不同），
   并在解谜阶段给出解释——不得让矛盾悬而不决。
4. **字面漏洞**：至少一条规则存在刻意留下的字面漏洞
   （"不要看它的脸"——背影呢？镜子反射呢？）；
   破局优先走漏洞与逻辑推演，**不靠武力平推**。
   陷阱型伪漏洞（找到的"漏洞"正是陷阱）必须埋有前文证据链。
5. **违反当场见效**：每条规则的违反后果必须当场可见——
   写正在发生的死亡与异常，不写倒计时。
6. **认知危害有界**：规则可以攻击"解读规则的能力"本身
   （"怀疑是一种症状"式），但必须有边界与解除条件，不得无限升维。
7. **NPC 之死立威**：用配角/NPC 违规死亡建立威慑与示范，
   死亡留账（死于哪条规则、哪个误读），不得暗复活。
8. **恐怖纪律**：恐惧来自"不知道该不该信"、未知与人心；
   恐怖画面具体而克制（声音、痕迹、小物件），血浆猎奇克制。

## 三、长篇节奏模板

| 层 | 该发生什么 |
|---|---|
| 开篇三章 | 入场即死局 + 300 字内抛出核心规则 → NPC 试错立威 → 主角完成第一次规则反杀 + 幕后钩子 |
| 中期 | 规则反转（已确认的认知被推翻）、真相层次逐层剥离、规则来源之争 |
| 后期 | 制定者真相收拢：规则的制定逻辑、矛盾规则的由来全部归因于底层真相 |
| 每卷 | 至少一次"规则反转"或"漏洞发现"作为卷级爽点 |

## 四、反模式（禁止）

- **纯文本怪谈化**：只有规则没有主角成长线与解谜递进。
- **规则说明书**：规则给出后从不动、不咬人、不互斥，只当背景板。
- **无意裂缝**：破局靠作者没想明白的逻辑漏洞，而非刻意设计的字面漏洞。
- **恐怖真空**：写成正面对轰动作片，规则沦为贴在墙上的装饰。
- **规则变形记**：规则随剧情需要随意改写、事后追加解释。

## 五、对设定阶段的要求

勾选本卡时，设定敲定阶段需额外拍板：
- 每个怪谈场景的底层真相（一句话）与由它派生的规则清单初稿
- 规则来源清单（谁写的、在哪、怎么被找到）与真规则/假规则判定表
- 字面漏洞预案（哪条规则留了什么漏洞、主角怎么发现）
- 矛盾规则的制定者视角解释
- 诡异存在的行事边界（它受哪些规则约束）

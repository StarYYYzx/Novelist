# 网文章节节奏

> v2（2026-10-25）并入调研报告（2026-10-24）的平台节奏参数与章末钩子方法论。

## 一、平台节奏三型（设定阶段拍板，全书贯彻）

| 档 | 单章字数 | 开篇要求 | 爽点密度 | 节奏本质 |
|---|---|---|---|---|
| **起点** | 2000–4000（3000 主流） | 简介头两行呈现卖点；第一章承担"封面"功能 | 大爽点留间距，章内有钩即可 | 故事发展慢 + 情节详略慢（**双慢**） |
| **番茄** | 2000–2500 | 前 300 字必须引爆冲突；三句话不劝退；禁大段写景/心理/背景 | 极高：一屏一个钩子 | 故事发展快 + 情节快（**双快**） |
| **飞卢** | 2000 左右 | 书名+简介即抛最大期待；第一章全套出齐 | 每 2000 字小爽点 | 故事发展快 + 情节详略慢（**快慢**） |

**飞卢辨析（关键，防学错）**：飞卢快的只是**故事发展速度**，情节详略上其实很慢
——领证能写一章、试婚纱再写一章。学飞卢要学"**情节选择挑剔 + 具体情节细写**"
（只选最经典、最高光、最爆炸的情节去写，选中的往细里写），
不是把所有事写得匆匆忙忙。

## 二、篇幅

- 以本章内容需要为准，**写足场面与反应**。篇幅不足时的补写顺序：
  先补**感官细节与环境反应**，再补**配角反应镜头**，最后才补主角内心——
  主角独白最容易注水。
- 篇幅是否达标由生成后的统计/验收环节负责。本项目**不在 prompt 里注入字数
  目标**（2026-09-05 决定：注入字数会诱发凑字），因此卡只规范"不足时补什么"。

## 三、单章结构

```
开场钩子（200 字内进入冲突，禁止大段环境铺陈与背景说明）
  → 中段 2-3 个节拍（每拍：目标 → 阻碍 → 结果 → 新信息）
  → 章末钩子（六型真钩子选一，见下节）
```

## 四、章末钩子：六型分级与还款纪律

> 章末读者只有三种状态：满足（明天可能回）、困惑（只会弃）、不甘（会点下一章）。
> 钩子要制造的只有不甘。**钩子是借据，不是诱饵——诱饵骗一次，借据借一辈子。**

六种真钩子按强弱排序：
1. **反转钩**（最后一句推翻前文因果）——最强也最贵，一章只用一次，
   一卷不超过两次；
2. **代价钩**（决定已做、账单未到："他按下了按钮。三秒后，整栋楼的灯灭了"）
   ≈ **关系钩**（一个动作当场改变两人关系）；
3. **倒计时钩**（"婚宴定在初八。距离初八还有六天"——核心不是紧，
   是数字让读者自己算）；
4. **信息钩**（给一半藏一半："灰烬里剩下半行字：你父亲没有死"——
   读者自己想的悬念比作者给的牢）；
5. **期待钩**（"三天后，宗门大比"——不制造焦虑，制造预约；最弱但必需）。

**四种伪钩子（禁止）**：机械断章（"就在这时，门外传来敲门声"——与本章内容无关）；
作者跳出来喊（"他能否活着走出林子？请看下章"）；空转危机（每次章末生死关头、
下章开头三句化解）；断在动作中间且无信息（要断就带信息："他一拳挥出——
对面那个人没有躲。而是笑了。"）。

**还款纪律**：强钩快还（反转/生死危机最好下一章回应，拖三章读者觉得被耍）；
弱钩慢还；还的时候**多给一点**（等了三章的答案要值三章）；
**埋十个必须还八个以上**——爱挖坑的标签一旦贴上，追读即崩。

## 五、反模式（禁止）

- 章末用"他知道，这只是一个开始"式总结/抒情/感悟收尾。
- 四种伪钩子（见上节）。
- 大段静态说明（设定说明书式开场）。
- 一章之内两个同等强度的高潮（把一个留到下一章）。
- 相邻章节使用相同的节拍模板。

【单章节奏规范（硬约束）】

1. 开场 200 字内进入冲突，禁止大段环境铺陈与设定说明书式背景交代。
2. 中段 2-3 个节拍，每拍都要有：目标 → 阻碍 → 结果 → 新信息。
3. 篇幅以内容需要为准，写足场面与反应；不足时优先补感官细节、环境反应
   与配角反应镜头，不靠主角内心独白或重复叙述凑数。
4. 章末 3 行内必须留真钩子，六型选一：反转钩（推翻前文因果，一卷至多两次）、
   代价钩（决定已做账单未到）、关系钩（一个动作改变两人关系）、倒计时钩
   （给出数字让读者自己算）、信息钩（给一半藏一半）、期待钩（预约型，最弱但必需）。
5. 四种伪钩子禁止：机械断章（最后一秒插入与本章无关的动静）、作者跳出来喊
   （"请看下章/他能否"式）、空转危机（章末生死关头下章三句化解）、
   断在动作中间且不带新信息。
6. 严禁用总结句、抒情句、感悟句收尾（如"他知道这只是一个开始"）。
7. 不得在对话中途或动作完成前断章；不得在高潮之后追加解释性尾巴。
8. 一章内不得出现两个同等强度的高潮，第二个留到下一章。
9. 钩子是借据：强钩下一章内回应，还的时候要比读者等到的多给一点；
   章末制造的危险与悬念必须在后续章节真实结算，不得空转。

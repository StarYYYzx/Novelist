# 网文章节节奏

## 一、篇幅

- 以本章内容需要为准，**写足场面与反应**。篇幅不足时的补写顺序：
  先补**感官细节与环境反应**，再补**配角反应镜头**，最后才补主角内心——
  主角独白最容易注水。
- 篇幅是否达标由生成后的统计/验收环节负责。本项目**不在 prompt 里注入字数
  目标**（2026-09-05 决定：注入字数会诱发凑字），因此卡只规范"不足时补什么"。

## 二、单章结构

```
开场钩子（200 字内进入冲突，禁止大段环境铺陈与背景说明）
  → 中段 2-3 个节拍（每拍：目标 → 阻碍 → 结果 → 新信息）
  → 章末钩子（悬念 / 反转 / 新信息，三选一）
```

## 三、章末铁律

1. **章末 3 行内必须出现钩子**。禁止用总结句、抒情句、感悟句收尾
   （"他意识到这方寸之地，或许就是通往神座的起点"这类是**抒情收束，不合格**）。
2. 钩子三选一：**新信息**（读者和主角刚知道一件改变局势的事）、
   **反转**（前面的理解被推翻）、**悬念**（危险逼近但未发生）。
3. **断章位置**：不得在对话中途切断（除非是刻意的悬念断句），
   不得在动作完成前切断，不得在情绪高潮之后追加解释性尾巴。

## 四、反模式（禁止）

- 章末用"他知道，这只是一个开始"式总结。
- 大段静态说明（设定说明书式开场）。
- 一章之内出现两个同等强度的高潮（应把一个留到下一章）。
- 相邻章节使用相同的节拍模板（见 invincible-flow 卡的反重复条款）。

【单章节奏规范（硬约束）】

1. 篇幅以本章内容需要为准，写足场面与反应；不足时优先补感官细节、环境反应
   与配角反应镜头，不靠主角内心独白或重复叙述凑数。
2. 开场 200 字内进入冲突，禁止大段环境铺陈与设定说明书式背景交代。
3. 中段 2-3 个节拍，每拍都要有：目标 → 阻碍 → 结果 → 新信息。
4. 章末 3 行内必须留钩子：新信息、反转、悬念三选一。
   严禁用总结句、抒情句、感悟句收尾（如"他知道这只是一个开始"）。
5. 不得在对话中途或动作完成前断章；不得在高潮之后追加解释性尾巴。
6. 一章内不得出现两个同等强度的高潮，第二个应留到下一章。

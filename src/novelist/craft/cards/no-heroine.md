# 无女主

## 一、本体定义（世界是什么）

1. **准确定义**：无女主 ≠ 没有女性角色——是**没有任何与主角
   产生暧昧关系的女性角色**。主角不对任何人动心（含未出场与
   回忆中的对象），无似是而非的两性倾向描写；他人对主角的
   单向感情可以有，但主角不回应、也不因该感情被牵扯进剧情。
2. **动机**：感情戏不是必需品——写不明白的感情线比没有更伤书
   （模板女主加的分，抵不了剧情被拆减的分）。无女主是把情感
   重心移到亲情、友情、师徒上——这些人人亲历，实感更强。
3. **情感锚**：主角的情绪落点必须有替位——家人、兄弟、师徒、
   宿敌、事业理想；至少一条情感锚贯穿全书并承担关键情绪节点。
4. **责任转移**：没有感情钩子后，剧情节奏与人物塑造承担
   **全部留人责任**——无女主文的剧情密度与角色塑造必须更扎实。

## 二、呈现规范（硬约束，人设/风格不得覆盖）

1. **互斥条款**：本卡与"后宫""单女主"工艺卡互斥，感情结构三选一。
2. **感情线铁幕**：全书零感情线；主角不得对任何角色动心；
   禁似是而非的两性描写、禁暧昧回应、禁上床剧情
   （无感情纯交易且不影响主角主观亦不建议）。
3. **单箭头处理**：他人对主角的单向感情须明确止步——
   主角不回应、不利用、不因此被牵扯进剧情线。
4. **情感锚在场**：至少一条非恋爱情感锚贯穿全书；
   情感锚角色（兄弟/家人/师长）有独立人格与自身目标，
   禁工具人兄弟、禁只在主角需要时出现的情感挂件。
5. **女性角色正常存在**：女性角色以同事、对手、长辈、盟友身份
   正常出场并按一般角色标准塑造；禁为"避嫌"把女性角色
   全删或全员空洞化。
6. **节奏补位**：原由感情线承担的留人功能由剧情钩子承担——
   每卷至少一条非感情向的期待钩子（悬念/目标/对手升级）。
7. **禁硬塞**：禁为"证明主角是什么人"硬塞功能性暧昧对象；
   禁结尾强行发糖或临场开感情线。

## 三、长篇节奏模板

| 层 | 该发生什么 |
|---|---|
| 第一卷 | 情感锚入场并立住（家人/兄弟/师长），与主角建立非恋爱羁绊 |
| 中间各卷 | 情感锚与主线交织：兄弟并肩、宿敌升级、师长托付；羁绊经事件检验 |
| 后期 | 情感锚收束：守护/传承/和解/超越，情绪落点闭环 |
| 每卷 | 至少一次情感锚相关的情绪高点（非恋爱：牺牲/信任/背刺/重逢） |

## 四、反模式（禁止）

- **避嫌式空城**：女性角色全灭或全员背景板，世界失真。
- **暧昧擦边**："她们都不是女主"式自欺——有暧昧实感的角色堆在主角身边。
- **兄弟工具人**：情感锚角色只在主角需要时出现提供情绪支持。
- **无情感锚**：主角情绪无落点，读者无共鸣可抓。
- **结尾发糖**：全书无感情线、结局突兀配对。
- **单箭头牵引**：配角的暗恋反复把主角拖入感情剧情。

## 五、对设定阶段的要求

勾选本卡时，设定敲定阶段需额外拍板：
- 情感锚选择（亲情/兄弟/师徒/宿敌/理想，至少一条）与分布表（按卷）
- 单箭头角色清单（若有）与止步方案
- 每卷非感情向期待钩子清单（悬念/目标/对手）
- 情感锚角色的完整人设卡（独立目标，与主角的羁绊事件链）

# 无敌流 / 碾压流

## 一、机制定义

1. **边界必须清晰且可量化**：无敌不是"很强"，是"在某范围内绝对不可被伤害"。
   范围用什么度量，必须在第 1 章就让读者能感知（半径 / 步数 / 一院之地 /
   一炷香时间 / 某个条件）。边界模糊 = 张力消失。
2. **代价必须是"边界之外的无能"**：主角在边界外与常人无异（甚至更弱）。
   无敌流的张力**不来自"能不能赢"，而来自"能不能把对手弄进边界里"**。
3. **无敌性只来自机制，不来自主角修为**：主角本人可以毫无修为。
   敌人越强，越要强调"他连一根手指都比不上对方，但对方进不来"。

## 二、爽点结构（标准五拍）

```
外人不知情 → 挑衅/入侵 → 跨过边界的瞬间画风突变 → 认知崩塌 → 旁观者误读并传播
```
- 第五拍"误读与传播"是长篇的复利：外界会把主角的行为解释成神迹/古老传承/
  某位隐世大能，这种误读要在后续卷持续发酵。
- 反差幽默来自**视角落差**（主角在心里算柴米油盐，外界在脑补圣人降世），
  不是主角自己吐槽。

## 三、扩张节奏（长篇进度条）

- 每次扩张都**必须由任务/事件驱动**，且留下可核对的账目（数值 / 范围 / 时间点）。
- 扩张后必须出现**新的、更大的麻烦**（被更高级的存在注意），否则爽点通胀。
- 反模式：主角在没有任何代价的情况下悄悄变强——读者没有进度条就没有期待。

## 四、反模式（禁止）

- **单章内重复同一碾压模式 ≥2 次**（"外人进来→被吓退"连写两遍即注水）。
  同卷内不同章节也应换模式：硬闯 / 试探 / 围观 / 请外援 / 误入。
- 让主角在领域外也能碾压（破坏代价模型）。
- 让敌人"因为剧情需要"突然能突破无敌边界而无铺垫。
- 主角自报无敌范围时把它说得比当前实际更大（设定超写，会摧毁进度条）。

## 五、对设定阶段的要求

- 无敌边界的初始度量（多大？）、度量单位（半径/步数/面积）
- 扩张的驱动物（任务 / 货币 / 条件）与本书总档位（如：院子→村→城→州→天下）
- 主角的外部身份伪装（外界误读成什么）

【无敌流呈现规范（硬约束）】

1. 主角只在明确边界内绝对无敌，边界外与常人无异（甚至更弱）。
   张力不来自"能不能赢"，而来自"能不能把对手弄进边界里"。
2. 无敌的边界必须可被读者量化感知（半径/步数/范围/时长），
   不得含糊其辞。主角自报范围时必须与本书当前实际进度一致，不得超前。
3. 爽点标准五拍：外人不知情 → 挑衅入侵 → 跨过边界瞬间画风突变 →
   认知崩塌 → 旁观者误读并传播。反差幽默来自视角落差，
   不是主角自己跳出来吐槽。
4. 单章内不得重复同一碾压模式两次；同卷不同章节须轮换模式
   （硬闯/试探/围观/请外援/误入）。
5. 无敌范围的每次扩张都必须由任务或事件驱动，并留下可核对的账目
   （数值、范围、时间点）；不得无代价地悄悄变强。
6. 扩张后必须引出更高级存在的注意，避免爽点通胀。

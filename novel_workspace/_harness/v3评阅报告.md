## 三、新链路验证结论（本次测试的目的）

**1. 事件循环成立（ADR-013 真落地）。**
每章 3 个 key_events 生成 3 段、段间带上一事件末尾作接缝，每段写完立即编纂回写——
**章内事件间"先忆"闭环第一次真实跑通**（v2 是整章写完后才回写）。15 个 key_events
全部落地，且 3 章 = 6 条事件（编纂员把一段拆出 2 条），比细纲声明得更细。

**2. 世界状态层能兜住跨章事实。**
- 林峯从"青云宗外门"→"杂役院阴影"→"主峰之巅"的位置链在 5 章间连续；
- 血手长老（金丹初期）被一指轰杀，终版 worldstate 标记阵亡；
- 物品链（太上忘情录系列）持续追踪。
- **代价是编纂噪声**（见第五节）——9B 的状态行质量偏低，需要清洗层兜底。

**3. R-STATE 第一次在真实语料上抓到东西（这是好事）。**
3 条 block 全部是"境界倒退"：吴虎"炼气七层→炼气期"（细分丢失的假倒退）、
血手"金丹初期→金丹中期（跌落）"（LLM 把括号注释写进了修为字段）。
修复 `parse_realm`（剥离括号注释、无法识别的细分跳过）后 0 告警。
**结论：确定性规则对"编纂层自身的噪声"比 LLM 审校更可靠**——这正是硬状态层存在的理由。

**4. 9B 审校师这次真的抓到了问题。**
第 2 章 block=3：大比中出现"击杀/尸体"违反"不得伤及性命"铁律、林峯当众展露
金丹后期与人设冲突。与 v2（跨章战力跳级漏报）相比，**把铁律和人物卡放进审校
prompt 后 recall 明显提升**。但第 4 章的"系统被写成有身体"仍漏报——审校师
对"非实体角色"这种设定细节能力不足。

**5. 剧本草稿（档 2）可商用。**
第 4 章成文生动，系统毒舌人设立住了（"宿主，别浪"）。成本 ×2 但无失控。
已知缺陷：剧本里的重复台词被叙事化照搬（屠九一句话一字不差说了两遍）。

## 四、样章点评（第 4 章·血刀来袭，剧本草稿产物）

- **好的**：屠九踩吴虎断臂的暗场开局；系统毒舌音色与林峯淡漠形成对位；
  "一指轰杀金丹初期"与 key_event 咬合；结尾魔主残魂锁定林峯与第 5 章钩子衔接。
- **缺陷 1（台词复读）**：屠九"血手长老说了，今晚要血洗青云宗……"一字不差出现两遍。
  剧本素材里的重复对白在叙事化时未被去重。
- **缺陷 2（非实体角色具身化）**："**两人**身影一闪"——无敌系统是声音，没有身体。
  审校师 block=0 漏报。

## 五、本次实测暴露的缺陷清单

| # | 缺陷 | 处置 |
| --- | --- | --- |
| S-1 | **状态行占位词污染**：LLM 输出「修为：无变化」「受伤：无」，被当真实变更写入，林峯修为一度被覆盖成"无变化" | 已修：parse_state_lines / apply_delta 双层 NOOP 过滤 |
| S-2 | **括号注释写进修为**：「金丹中期（跌落）」| 已修：parse_realm 剥离括号 |
| S-3 | **同物异名物品堆积**：《太上忘情录》残篇/残卷/圆满 各存一条 | 已修：获得 按顿号逗号拆分 + 去重 + 上限 20 |
| S-4 | **死亡抽取不可靠**：血手长老被轰杀，编纂员未输出阵亡行，worldstate 未标 dead（人工回填） | 待办：死亡检测需强化（或由 R-STATE 死而复生检查兜底） |
| S-5 | **剧本台词复读**：重场戏对白一字不差重复 | 待办：叙事化 prompt 加"去重重复对白"指令 |
| S-6 | **非实体角色具身化**："两人身影一闪" | 待办：审校 prompt 加"系统/声音类角色无身体"约束 |
| S-7 | v3 harness 未接**自动修订**（ch2 的 block=3 只记录未驱动重生成） | 待办：v2 有的 revision 步骤没带进 v3 |

> 说明：S-1/S-2/S-3 在 ch1 后即修复，但**运行中的进程不会重载修复后的代码**，
> ch3–5 仍按旧逻辑写入噪声；终态已用清理脚本回填（林峯金丹后期、血手金丹初期+阵亡等），
> 下一轮运行将直接干净。

## 六、遗留与建议

1. **世界状态需要一个"清洗层"**：9B 的状态行噪声率高（占位词/括号/同物异名/一票多物），
   parse 层修了三轮。建议下一轮：状态行改由**规则校验后**才落盘（非法值丢弃而非跳过），
   并给 R-STATE 加"编纂噪声"识别（realm 含括号/无 → 记 warn 不记 block）。
2. **自动修订接回 v3**：审校 block 命中时应带审校意见重生成（v2 已有该步骤）。
3. **对白区分度度量**（第三批第 2 条遗留）：剧本草稿 vs 直出的角色声音区分度尚无量化指标。
4. **死亡抽取**：S-4 建议在编纂 prompt 里把"阵亡"单列强调，或接受 R-STATE 死而复生兜底。
